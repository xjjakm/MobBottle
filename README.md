MobBottle
===

Minecraft26.2 生物瓶模组。

---

## 概要
这个模组添加了一个可以将生物抓到瓶子里的物品；展示瓶直接右击放出生物，左/右键直接抓生物， Shift+左键可以抓交易类生物， Shift + 右击可以将展示瓶放在地面。

右键改变显示：

- 镐：生物位置上移；

- 锹：生物位置下移；

- 斧：生物变小；

- 锄：生物变大；

- 剑：隐藏瓶子 。
## 注意事项
支持版本
- Minecraft 26.2
- Fabric 0.19.5
- 需要fabric api

因为是开发中的MOD，可能会出现问题。
使用这个MOD时请自行备份并自行承担风险。
