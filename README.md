MobBottle
===

Minecraft26.2 生物展示瓶模组非官方版。

---

## 概要
这个分支与上游功能一致，只是添加了一个简体中文支持

这个模组添加了一个可以将生物抓到瓶子里的物品；展示瓶直接右击放出生物，左/右键直接抓生物， Shift+左键可以抓交易类生物， Shift + 右击可以将展示瓶放在地面。

右键改变显示：

- 镐：生物位置上移；

- 锹：生物位置下移；

- 斧：生物变小；

- 锄：生物变大；

- 剑：隐藏瓶子 。

冷知识：你可以通过修改nbt中的生物名字来决定装的生物，如果生物被栓绳栓着，捕捉后在栓绳附近放这个生物还会被栓绳栓着
## 注意事项
支持版本
- Minecraft 26.2
- Fabric 0.19.5
- 需要fabric api

因为是开发中的MOD，可能会出现问题。
使用这个MOD时请自行备份并自行承担风险。
