MobBottle
===

Minecraft 26.3 生物展示瓶模组（Fabric 非官方版）。

---

## 概要

这个模组添加了一个可以将生物封装进瓶子、作为装饰品展示的「生物展示瓶」。放置后可以调整生物的大小、高度与朝向，观赏被封印的生物。

**玩法流程**：

- 手持空瓶（空生物展示瓶）**右键生物** → 捕获；
- 手持生物瓶**右键地面** <kbd>Shift</kbd> → 放置展示瓶（生物被封印在瓶内）；
- 手持生物瓶**右键生物** → 释放生物；
- <kbd>Shift</kbd> + 左键生物 → 捕获交易类生物。

**右键放置后的展示瓶可调整**：

- 镐：生物位置上移；
- 锹：生物位置下移；
- 斧：生物缩小；
- 锄：生物放大；
- 剑：切换外装方块（可右键套一个方块外观/移除）；
- 木棍：切换人偶模式(让生物变的和装进去前一样大)。

**冷知识**：你可以通过修改 NBT 中的生物名字来决定装的生物；如果生物被栓绳拴着，在栓绳附近释放它，它仍然会被拴着。

## 合成

主配方（3×3 有序）：

```
[木台阶] [木台阶] [木台阶]
[ 玻璃 ] [ 宝石 ] [ 玻璃 ]
[ 玻璃 ] [ 玻璃 ] [ 玻璃 ]
```

- 木台阶：任意木台阶（`#minecraft:wooden_slabs`）
- 玻璃：普通玻璃（`#c:glass_blocks/cheap`，不含遮光玻璃）
- 宝石：钻石 / 绿宝石 / 青金石 / 紫水晶碎片 / 海晶碎片 / 下界石英 任选其一（`#c:gems`）

转换配方：瓶 ↔ 空瓶（1 个直接在合成台互转）。

**配方解锁**：获得木台阶 / 玻璃 / 宝石中的任意一种材料即自动解锁主配方（不再需要先合成一次）；持有瓶子即解锁转换配方。

## 注意事项

支持版本：

- Minecraft 26.3
- Fabric Loader 0.19.5
- 需要 Fabric API

因为是开发中的 MOD，可能会出现各种问题。使用这个 MOD 时请自行备份游戏存档并自担风险。
